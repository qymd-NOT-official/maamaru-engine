# 识别模板整理

模板仍以 `resource/base/image/` 为根目录。逐个玩法整理，先登记逻辑名和旧路径兼容，再归档图片；不按文件名猜位置，不跨服找替代图。

## 首批：出阵相关模板（2026-10-31）

| 旧路径 | 逻辑名 | 当前路径 |
|---|---|---|
| `决定.png` | `@sortie/decide` | `sortie/decide.png` |
| `ui本丸.png` | `@home/screen` | `home/screen.png` |
| `通用_确定.png` | `@dialog/confirm` | `common/confirm.png` |
| `否.png` | `@dialog/no` | `common/no.png` |

这四张沿用仓内原图，只移动位置，未重裁、缩放或调整颜色。其余模板暂留原位。

绑定统一保存在 `resource/base/server_packs/cn.json`：`templates` 绑定逻辑名和实际文件，`template_aliases` 将旧路径指向逻辑名。别名只允许指向本服已登记的逻辑名，不允许别名链或缺文件后回退到旧图。

设备匹配、匹配分数和流程工坊的旧路径预览共用 `server_pack.resolve_template_path`。旧用户配置、旧自定义流程无需改写；新路径和旧路径找到同一张图。未登记的自定义相对路径保持可用，日服包不继承国服别名。

本次没有修改用户配置结构，也没有完成出阵玩法的双服迁移。后续拆出阵时，将对应图片、识别词和坐标逐步移入素材包；其他玩法按批次推进。

验证需覆盖老配置不改写仍可解析、匹配与分数入口一致、旧流程预览、两服隔离、无效映射拒绝，以及移动前后图片字节一致。新增或替换图片仍须从实际运行截图通道采样。
