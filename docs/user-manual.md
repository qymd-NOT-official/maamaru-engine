# まあ丸使用说明

这份说明写给第一次使用まあ丸的审神者。日常设置都可以在本丸面板中完成，不需要手动编辑配置文件。

> [!NOTE]
> まあ丸目前主要支持 MuMu 12 与 1280×720 游戏画面，已经过维护者长期实机运行，也有非技术用户完成安装和日常使用。游戏更新、新地图、不同模拟器或分辨率仍可能影响画面识别；第一次使用新任务或更换运行环境时，建议先短跑确认。

## 安装与启动

从 [GitHub Releases](https://github.com/qymd-NOT-official/maamaru-engine/releases) 下载最新版：

- `maamaru-setup-v*.exe`：安装版；
- `maamaru-launcher-v*.zip`：免安装版，解压后运行 `まあ丸启动器.exe`。

第一次启动：

1. 打开 MuMu 12，把游戏分辨率设为 1280×720，并进入《刀剑乱舞 ONLINE》。
2. 运行 `まあ丸启动器.exe`，等待检查完成。
3. 如果启动器没有找到模拟器，点击“选择模拟器”，选中 MuMu 安装目录。
4. 检查“程序文件”“用户数据”“运行环境”“面板端口”和模拟器相关项目；有提醒时先按提示处理。
5. 点击“启动まあ丸”，进入完整本丸面板。记账和预算从“仓库”进入。

启动器常用按钮：

- **重新检查**：重新读取程序、端口、模拟器和 ADB 状态。
- **修复环境**：环境文件不完整或运行依赖异常时使用。
- **数据目录**：打开当前配置、日志和成绩单所在目录。
- **迁移数据**：把用户数据复制并校验到其他磁盘，详见[更新、卸载与数据迁移](#更新卸载与数据迁移)。
- **选择模拟器**：自动发现失败时，手动选择 MuMu 目录。
- **反馈错误**：面板打不开时，从启动器导出脱敏反馈包。
- **检查更新**：检查正式 Release；下载失败可以重试，安装前仍需用户确认。

## 面板怎么用

面板顶部按日常使用顺序排列：

| 入口 | 可以做什么 |
|---|---|
| **我的本丸** | 看本丸近况、归期、狐之助小报和动态，写小记、整理自己的档案 |
| **规划** | 看活动进度和预算、设资源目标、安排联队战与定时任务流、查看远征建议 |
| **功能** | 在执务台看当前任务和日志，在流程搭建中保存任务流，在玩法设置中运行单项任务 |
| **仓库** | 看家底、收支来源、收刀与任务记录，手动记账，导入或导出旧账 |
| **刀剑** | 更新刀账、标记常用和要练的刀，编辑与套用部队预设 |
| **设置** | 调整名单、通知、主题和运行相关设置 |

「我的本丸」的动态来自确认过的收刀、远征、锻刀与刀剑整理记录，也可以写自己的小记。近况中的归期会标明读取时间；时间已到不等于已经领取。伤势以出阵前的画面识别与安全检查为准。

独立账房入口与 Android APK 暂停提供，已有数据保留。请从完整面板的“仓库”使用账房。

单项玩法的「保存配置」保留选项，「开始任务」立即按当前页面设置运行。任务流使用「保存流程」与「运行这条」；有未保存的修改时，可以「保存并运行」。

同一时间只能运行一项任务。运行中可以切到其他页面，随时回「功能 → 执务台」看日志或停止任务。停止后先看模拟器停在哪个页面，再决定是否重新运行。

### 第一次运行前检查

- 地图、部队、次数和结束动作是否正确；
- 部队没有重伤成员，御守和刀装符合自己的习惯；
- 手入黑名单、刀解白名单和活动目标名单已经检查；
- 自动补充手形或提灯是否允许消耗小判；
- 自动手入是否可能消耗加速符；
- 自动补充刀装是否允许消耗现有刀装；
- 电脑休眠、关闭模拟器等结束动作不会影响其他正在运行的事情。

## 任务流与一键日课

想把每天要做的事串起来，打开「功能 → 流程搭建」。默认「一键日课」已经排好常用步骤，可以直接运行，也可以从左侧菜单复制一份再改。

1. 选择已有流程，或点击「新建流程」。
2. 添加、移除或调整步骤顺序，展开步骤填写部队、圈数和其他选项。
3. 为每一步选择失败后「停下等我」或「继续下一步」。后者会记下失败，再执行后续步骤，不会把失败算成完成。
4. 保存流程，再点击「运行这条」；想晚些开工，可以到规划页添加定时启动。

可组合的步骤包括开模拟器、登录、签到、万屋领奖、演练、远征、内番、锻刀、刀解、合成、出阵、活动、任务奖励、库存快照、账本同步和收尾动作。页面中的步骤设置决定本次具体做什么；退出游戏、关闭模拟器或电脑休眠等动作请在保存前核对。

普通玩法步骤没有专用设置时，沿用「玩法设置」中已保存的配置；在步骤里填写后，改为使用这一步的专用设置。日课的「出阵安排」保留自己的地图、部队、圈数、伤势处理等设置，不会被独立玩法悄悄覆盖。独立「手入」与连续出阵受伤后的处理也分别设置。

「功能 → 玩法设置 → 一键日课」仍可勾选所需步骤后立即运行。长期重复使用或需要调整顺序时，使用流程搭建中的日课更方便。

普通锻刀使用空闲炉，不会为了凑次数消耗加速符；「十连限锻」会消耗加速符，详见[锻刀](#锻刀)。库存快照和账本同步用于更新记录，不代表前面的任务都成功；收工后仍要看各步结果。

## 规划与定时开工

规划页把今天的时间表、活动目标、家底和远征建议放在一起。

- **活动目标**：按现有进度、剩余时间与圈速估算还要打多少圈、花多少小判。没有实测时可以填写估计，预测不是收益保证。
- **资源目标**：选择攒到多少或截止日期，根据现有记录估算进度。大阪城目标填写活动结束时希望留下的小判库存；江户城会结合钥匙目标、免费手形与场均钥匙估算补票预算。
- **狐之助的关注项**：可以交给狐之助建议，也可手动改。远征推荐使用同一个关注项；目标资源暂时排不出时，会说明占用、缺刀种、总等级要求和当前差距。
- **可安排的小判**：会扣除已留出的预算；超出免费手形的联队战预计开支也计入安排。

### 安排联队战

1. 点击时间表中的联队战建议块，打开今日安排。
2. 核对开工时间与圈数，必要时自己修改。
3. 点击「保存并到点开工」。已保存的安排显示在时间表和「今日安排」中，点击对应安排可修改或移除。

这里是实际执行的圈数，**默认手形不足时自动补充，会消耗小判**。联队战的部队、自动换队长等其他选项沿用已保存的玩法设置；定时执行时使用安排中的圈数与补手形设置。

修改相关玩法或任务流后，旧安排可能因设置变化而不启动。请重新打开安排核对并保存，不要以为修改玩法后旧预约会自动接受新设置。

### 定时启动任务流

点击「＋ 定时启动任务流」，选择已保存的流程和时间，再保存安排。它按流程保存的设置运行，不会把活动建议圈数塞进其他任务流。

到点时まあ丸面板需要保持运行，电脑不能休眠；定时联队战会准备模拟器和登录，普通任务流是否开模拟器、登录由流程步骤决定。已有任务运行时会等待接上。失败的安排会显示失败或停止，处理原因后重新安排；不想执行的段落直接移除。

### 远征与部队预设

推荐队伍达不到地图要求时，可以先按提示调整队伍，或使用已有部队预设。预设不会自动按资源缺口替您重新挑刀；确认成员、装备与目标队伍后再派出，详见[部队预设](#部队预设试用)。

## 刀账与所持名单

打开「刀剑 → 刀账」，进入游戏本丸后点击「更新刀账」。优先使用游戏记录中的所持名单，每振刀按唯一编号分别保存，同名刀不会因为名字相同就合成一条。

- **整本**：查看当前所持名单，可标记常用、特别关心或要练的刀。
- **待核对**：查看还不能确认的记录；缺少证据时不会把旧标注硬套到另一振同名刀上。
- **历史标注**：已经不在当前名单的刀保留原标注，不再算作现有所持。
- **更多 → 截图盘点（备用）**：操作游戏逐页识别刀账，供游戏记录无法取得时使用。平时优先「更新刀账」。

读取到锻刀结果、战斗掉落、收件箱领取，以及链结、习合、刀解的确认记录后，会更新对应的入手或消耗情况。收件箱中的刀要领取进入所持后才算当前所持；入手记录能够确认来处时会保留来源，不能确认时不补一个猜测。

这不是实时监听。游戏记录在主动更新或相关任务收工同步时读取；手动在游戏中整理了刀剑后，可以再点「更新刀账」。自己的标记和游戏所持事实分别保存，更新名单不会把旧标记转嫁给另一振刀。

## 出阵的共用设置

普通合战场和异去共用大部分战斗设置，大阪城也沿用伤势处理与补刀装规则。

### 自动行军与阵形

- **使用自动行军**：委托前同步游戏的详细设定，包括中伤停止、重疲劳停止、刀装破坏停止与索敌失败时的阵形。选择重伤停止时关闭游戏的中伤停止；同时允许手入与补刀装时关闭刀装破坏停止。重疲劳停止为独立开关，默认开启。游戏没有轻伤停止，选择轻伤停止时改用脚本行军。
- **关闭自动行军**：会检查并取消游戏之前留下的委托，避免游戏仍自行前进。
- **手动行军**：由まあ丸处理岔路和阵形。阵形可选手动或自动：手动固定使用所选阵形；自动交给游戏，游戏无法判断（索敌失败等）时まあ丸优先选择有利阵形，认不出再落回所选阵形。从手动切到自动只会影响下一次阵形选择，まあ丸仍会把当前这一场选完；确认阵形页面真正消失后才会继续战斗。

### 伤势停止与手入

- **伤势停止条件**：可以选择轻伤、中伤或重伤。无论配置哪一级，确认重伤时都不会强行出阵。
- **手入加速后继续**：修好当前出阵部队并使用加速符，然后继续剩余圈数。
- **手入后停止**：把符合条件的刀送去手入，本次任务不再续跑。
- **停止且不手入**：返回或停止点击，把后续处理留给玩家。

手入黑名单中的刀不会被自动送去手入。连续出阵使用“手入加速后继续”时，只处理当前出阵队，不读取独立手入工具的队伍设置。

### 自动补充刀装

自动补刀装与手入方式是两个独立开关。即使选择“手入后停止”或“停止且不手入”，也可以单独决定是否补刀装。

开启后，まあ丸会在首次出阵前把当前部队保存到游戏的“记录一”。只有点击出阵后实际出现“刀装未满”提示，才会尝试用记录一恢复并重新检查伤势。请不要在任务运行期间手动覆盖记录一。

### 自动换队长

合战场、异去和联队战可以开启自动换队长，并选择 5、10 或 20 点疲劳差阈值。まあ丸会在每圈出阵前读取当前部队疲劳，把符合阈值的成员调整到队长位。

队长已经合适、疲劳差不足、疲劳读取失败或拖动没有生效时，不会强行继续调整。它是战斗内策略，不需要单独运行。日课出阵使用自己的开关和阈值；任务流的普通玩法步骤按该步骤专用设置或已保存的玩法设置执行。

### 王点前撤退

王点前撤退只在普通合战场关闭自动行军后生效：

1. 在“合战场”中关闭自动行军。
2. 打开“王点前撤退”。
3. 选择地图、部队、圈数和伤势处理方式。
4. 第一次在新地图使用时先短跑，观察日志能否稳定报告小地图状态。

まあ丸会读取右上角小地图，确认下一步将进入王点时主动返回本丸。小地图无法确认时会继续普通行军，不会把“不知道”当成撤退信号。

王点前撤退完成也算一圈。它可以避免地图因反复击破王点而出现检非违使，但不能移除已经出现的检非违使。

## 部队预设（试用）

在「部队预设」中选择目标部队和要安排的位置。可以从刀账选定具体一振，也可以只按刀名和形态建预设，不必先盘点整本刀账。后一种用法会在游戏名单中寻找确认上锁、等级最高且唯一的候选；最高级并列或名单读不清时，まあ丸会停下，不替您猜。

点开已选成员下方的「设置装备」，可按格选择刀装种类与品级，也可指定宝物、马和御守。没有填写的装备格保持原样；指定的装备找不到、同款实例分不清或换装后无法确认时，预设不会继续出发。

玩法设置中的部队选择和自定义工作流的「套用部队预设」可使用同一套预设。第一次使用请先安排容易复原的队伍短跑查看结果；目前不建议把重要队伍交给无人看守的预设任务。

### 大阪城指定楼层

需要固定挂机时，打开“指定挂机层数”并填写已解锁的 1～99F。不开启时，まあ丸不会选择楼层，只在进入大阪城后按游戏当前流程持续点击“行军”；楼层如何推进由游戏决定。

“小判掉落率实验”会记录能够确认的楼层、圈数和小判变化，用于本地成绩单估算；识别失败不影响挖地本身，也不会硬猜收益。

活动入口、页面布局或规则更新后，如果まあ丸无法确认楼层或行军状态，会停止而不是盲目继续点击。

### 江户城潜入调查

江户城只智能跑 E4，其他难度不计划适配。まあ丸会读取剩余步数，优先经过设定路线中的节点，并在无法继续巡游时转向王点：

- “出阵次数”是本次最多运行的圈数，从 1 开始设置，不再使用 `0` 表示特殊行为。
- “是否补充手形”关闭时，现有手形不够完成设定次数便提前结束；开启后才允许在游戏补票弹窗中使用小判。弹窗无法确认时不会盲点消费。
- 江户城没有游戏自动行军，但每场战斗仍可选择手动或自动阵形；手动固定使用所选阵形，自动模式识别失败时优先选择有利阵形、认不出再落回所选阵形。
- 中伤可以继续巡游，确认重伤时仍会拦截出阵；页面、步数或战斗状态连续无法确认时会安全停止。
- 每圈结算会记录带回的钥匙、耗时和圈数，供“全部记录”和活动算盘使用。

当前巡游路线、识别范围和活动入口按本期实机画面制作。现有少量实测记录里钥匙表现不错，但不能据此保证每圈收益；活动复刻或游戏改版后，第一次运行请先只跑一圈观察。

### 活动资源消耗

- 联队战手形与异去提灯只有在开启自动补充时才会使用小判；关闭后资源不足即结束。
- 南瓜大作战的令牌自动购买目前禁用，令牌不足时结束。
- 江户城只有开启“是否补充手形”后才允许使用小判；无法确认补票弹窗时结束。
- 开启自动补充前先确认出阵次数和小判余额，避免把测试配置留成长期挂机配置。

## 远征、锻刀与其他独立工具

### 远征与自动排班

“远征”和“自动排班”是两种不同用法：

- **远征**：现在立即收取已经归来的队伍，等待十分钟内即将归来的队伍，并按“常用安排”重新派出；等待更久的本次跳过。
- **自动排班**：在设定时间接管已经打开的游戏并派遣。到点时面板、模拟器和游戏都必须保持开启。

配置自动排班后要点击“保存排班设置”。临时不希望まあ丸接管时，可以暂停 30 分钟、1 小时或今天不接管，不必删除原排班。

### 锻刀

独立锻刀会先收取已经完成的刀，再给空闲炉点火：

- “最多锻几炉”是本次上限，不会占用正在工作的炉；
- 普通锻刀不使用加速符；
- 可以添加一个或多个目标时长，命中后通过已配置的通知渠道报喜；
- 收取结果能够认出刀名时，会进入成绩单的“掉落结果”；认不出时只保留已确认的收取事件，不编造名字。

把“锻刀方式”切成“十连限锻”就是另一种玩法，限锻活动期间集中冲目标刀用：

- 每发十连固定消耗 9 张委托符、10 张加速符和配方×10 的四项资源，十把刀立刻进刀位，不等炉子；
- “锻刀数量”此时是要锻的总把数，按十连取整（填 50 就是 5 发十连，不足 10 把按一发算）；
- 可以填目标刀剑名字，出货会通过通知渠道报喜；每发十连都会先揭榜确认，开着“锻出目标就收手”会在命中后停止，不再烧下一发；
- 开跑前会先核对委托符和加速符库存；每发点火前还会重新读取刀位，读不清或不足 10 格都不会点火；
- “刀位不足时”默认停下等你处理。也可以明确选择只按白名单刀解本发缺少的数量，或只用现有重刀进行习合后复查；处理后仍不足会停下，不会固定多刀解 5 把；
- 每发的十把出货名单会尽量认出并写进成绩单。

锻刀会消耗木炭、玉钢、冷却材、砥石和委托符；十连限锻还会消耗加速符。开始前请确认配方、空闲炉、刀位和资源余额。

### 炼糖

炼糖是“收件箱领取刀剑 → 进入习合循环”的按需工具，不属于一键日课。它会消耗可以作为习合素材的重复刀剑：

- 进入习合列表后，只会点击列表中的第一把刀作为本体；
- 开始前请在游戏中保持开启“隐藏无法习合的刀剑”；
- 游戏中已上锁的刀无法被一键选择；
- 所持满、没有可喂的重复刀、收件失败或达到安全上限时结束；
- 第一次使用请在旁边观察，确认收件箱筛选、上锁状态和习合目标符合预期。

炼糖没有额外的刀名白名单，不要把“上锁保护”误解成项目会替你判断哪些刀值得保留。

### 库存快照

库存快照会手动读取八种资源并刷新本丸看板。平时锻刀收工和运行中的顶栏观察会顺路更新数据，通常不需要专门执行。

以下情况可以单独运行：

- 想立刻刷新看板；
- 日课没有执行锻刀，需要补一次完整盘点；
- 最近一轮挂机缺少收工盘点，而且挂机结束后没有进行任何会改变库存的操作。

## 名单与资源安全

- **手入黑名单**：名单中的刀不会被自动送去手入。
- **刀解白名单**：只有明确允许的刀才会进入自动刀解范围。
- **合成与活动目标名单**：限制对应流程可以选择或处理的刀剑。
- **游戏上锁状态**：炼糖依赖游戏本身的上锁保护，不使用刀解白名单。

第一次运行手入、刀解、合成、炼糖或活动目标筛选前，请打开名单页面检查并保存。涉及刀剑、小判、加速符、刀装和锻刀资源的操作，不要只依赖默认值。

## 仓库与成绩单怎么看

打开「仓库」查看概览与全部记录。概览可切换最近 24 小时、7 天和 30 天；全部记录按日期查看任务和收支。记录只展示能够确认的结果，点过按钮或进入过页面不等于任务完成。

### 概览

- **现在的家底**：八种资源的最近读数、读取时间和所选时段的变化。没有读数的项目留空，较旧的库存不是实时余额。
- **本丸小结**：整理确认过的收刀、心愿刀、主要进账和花费，可继续查看来源或对应记录。
- **资源统计**：查看单种资源趋势或比较几种资源，点击日期追到当日明细。
- **收刀记录**：展示确认过的刀名、数量与来处，包括锻刀、战斗掉落和收件箱领取。来源能细分时细分，证据不足时不猜。

心愿刀在名单设置中维护，命中后会在小结报喜。名单不会因入手自动删除；想继续刷二号机可以保留，不需要时手动取消。

游戏记录与まあ丸执行记录会标明各自来源。账本同步会拉取日志、去敏记账，原始日志阅后即焚；页面展示保留下来的所需记录。同步不是实时监听，也不代表本次自动化全部成功。

“＋ 手动记账”下的三种记录含义不同：

- **记一笔收支**：一次填写这次获得或消耗的多种资源，正数是获得、负数是消耗；
- **补记一段活动**：记录玩家自己打的玩法、圈数和起止时间，自动算出圈速；
- **更新当前家底**：保存此刻看到的资源数字，作为库存快照。

玩家手动活动与まあ丸任务分开保存、分开计数；“全部记录”会用“你”标出手动记录。规划页需要圈速时，如果两边都有样本，会分别列出“まあ丸实测”和“你手动记的”，由玩家选择，不会混在一起求平均。

“我的手账”会按时间列出玩家自己补记的收支、家底和活动。每条都能修改或撤销；同一次操作中的多种资源仍作为一组一起纠正。这里只显示玩家手动记的内容，不混入まあ丸自动确认的流水和库存快照。

“家底概览”右上角的“账本进出”用来带走或带回记录：

- **导出 Excel 账本**：得到完整流水、当前家底、每日汇总和“可再次导入”五张表；想整理后再带回来时，只编辑“可再次导入”。
- **导出流水 CSV**：适合交给别的表格或分析工具，内容是完整流水。
- **选旧账预览**：支持 `.xlsx` 和 `.csv`。预览会先列出可导入、重复、冲突和无法识别的行，此时不会改账；有冲突时必须明确勾选确认。

まあ丸自动确认的流水只会导出，不能被旧表反向改写。真正导入前会先备份本地账本；重复记录会自动跳过，导入的内容会进入“我的手账”，以后仍能修改或撤销。

第一次打开空账房时，狐之助会用三步帮你安顿好：先读取家底，再决定要不要导入旧账，最后可选立一个想盯的目标。完整模式下，打开模拟器并进入游戏本丸，点击「读取游戏家底」即可读取游戏记录，再通过锻刀与所持道具画面盘点资源、小判和符；不会执行日课、锻刀或出阵。读取期间请暂时不要操作模拟器，已有任务运行时不能开始盘点；结果分别说明游戏记录和画面盘点是否完成，没读全可以重试，旧读数不会冒充本次成功。仓库「现在的家底」旁也保留这个按钮，之后随时能用。

旧账和目标都可以跳过；没有圈速和收益记录时，先选一个任务短跑，再用积累的记录规划。已经有家底记录的老用户不会看到首次引导；中途关闭会从当前步骤接着来，完成或选择“不需要引导”后不再出现。

24 小时概览会用纵向统计图把七种日常资源摊开（甲州金保留在账上，但不塞进日常变化图）：每柱按自身变化归一显示、按来源分色，柱顶保留真实数额，因此数量级相差很大的小判、四资源和符都看得清。7 天和 30 天仍按单种资源查看时间趋势，也可以手动选择少量资源对比。

### 记录来源与库存读数

- **游戏记录**：读取到的资源、物品、活动与刀剑记录，能确认来处时展示具体来源。
- **流程确认**：まあ丸在任务中确认完成的出阵、远征、领奖、锻刀、手入等事件。
- **库存实际变化**：两次完整库存读数之间真实识别到的数字差值。
- **玩家补充说明**：玩家主动说明两次任务之间做过什么，只补充上下文，不修改库存事实。

运行中顺路看到的一次顶栏库存只是“途中观察”，不能单独算成本轮收益。只有能够形成前后边界的库存读数，才会产生可信的资源变化。

流程确认的收支与库存变化对不上时，差值会单独保留。可以点击“这期间做过什么”，选择大概时间和操作类型；也可以选择“记不清了”“没有其他操作”或“不想说，记差值就好”。

### 资源变化与收刀记录

![仓库家底与本丸小结](assets/v1-ledger.png)

“仅供参考”“基本可信”或“账目完整”描述的是当前时间段的库存证据是否连续，不代表任务本身成功或失败。可信程度会综合当前范围内各资源的读数数量、连续性和数据缺口；需要判断某一天时，再点击图表查看当天明细。

收刀记录只展示能够确认的名字和来源。识别失败时可以从全部记录和日志确认任务是否完成，但不会补一个猜测的刀名。

### 全部记录

![按日期查看全部记录](assets/report-daily-records.png)

“全部记录”使用日历选择日期，并把当天的任务和活动放在一条时间线上：

- 一轮任务可以展开查看轮内出阵、远征、领奖、锻刀和资源收支；
- 江户城会显示完成圈数、实际耗时以及每圈带回的钥匙；
- 没有所属任务的活动才单独显示，避免同一件事出现两次；
- 系统观察和诊断细节放在更深层，不占满玩家时间线；
- 轻量任务记录与玩家说明长期保留，体积较大的 OCR 观察明细默认保留 90 天。

### 收工盘点失败时怎么补

只有**最近一条有开工盘点、但没有收工盘点的挂机记录**可以补盘：

1. 挂机结束后不要领取邮箱、任务奖励，也不要锻刀、手入、购买或进行其他会改变库存的操作。
2. 单独运行一次“库存快照”。
3. 打开“全部记录”，找到最近一轮挂机并点击“补上最近盘点”。
4. 确认这份快照没有被其他操作污染。

如果挂机结束后已经做过其他操作，就不要补盘。较晚的库存无法区分哪些变化来自挂机、哪些来自玩家，强行补上只会制造一份看似完整但实际错误的收益记录。

### 演练成绩

まあ丸会读取当前刷新场已经留下的胜利或败北章，把已有胜场计入本次目标，避免同一刷新周期重新运行时从零开始。结果没有明确识别时会标为待确认，不会直接当成败北或零胜。

记录保存在本机，包含已经读取的游戏记录、まあ丸执行记录和玩家手动记账。未同步、未接入或缺少证据的操作不会自动补全。

## 任务为什么停了

常见的安全停止原因：

- 检测到重伤或达到设置的伤势条件；
- 刀装不满，且没有开启或无法安全完成自动补充；
- 手形、令牌、提灯、小判或锻刀资源不足；
- 游戏更新、网络异常或弹窗没有恢复；
- 当前页面与设置的地图、楼层或活动入口不一致；
- 疲劳、阵形、王点或楼层等关键状态无法可靠确认；
- 一段时间没有任务进度，看门狗结束了可能卡死的进程。

处理顺序：

1. 查看日志最后几条可视化消息。
2. 看模拟器当前停在哪个页面。
3. 确认是配置不匹配、资源不足、游戏更新还是识别失败。
4. 修正原因后再运行对应任务，不要在原因不明时反复重跑整套日课。

紧急停止会直接结束任务进程，无法保证执行收工盘点或回到本丸。停止后请先确认模拟器页面和部队状态。

## 反馈错误

面板能打开时，点击日志右上角的“反馈错误”；面板打不开时，在启动器中点击“反馈错误”。把生成的 ZIP 和问题发生时的完整模拟器画面一起附到 [GitHub Issues](https://github.com/qymd-NOT-official/maamaru-engine/issues)。

反馈包只收集版本、系统摘要、启动失败记录、最近任务日志和少量框架文本日志。它不会包含まあ丸配置、API Key、聊天记录、库存、状态数据库或截图，并会遮掉本机用户名路径和常见密钥字段。上传前仍可自行解压查看。

提交问题时请说明：

- 使用的まあ丸版本；
- 模拟器与分辨率；
- 运行的任务和主要设置；
- 最后看到的日志与模拟器画面；
- 是否能稳定复现。

## 更新、卸载与数据迁移

### 更新

从旧用户名时期的版本升级到 v1.0.1，请从新仓库下载 Windows 安装器，安装到原位置；旧启动器的下载校验仍使用旧地址。配置与记录保留。v1.0.1 之后使用新仓库检查更新。

在启动器中点击“检查更新”，下载后确认安装。更新只替换程序文件，不删除用户数据；下载会校验官方 Release 文件的名称、大小和 SHA-256，安装失败时尝试恢复旧程序。

### 用户数据

安装版默认用户数据目录：

```text
%LOCALAPPDATA%\Maamaru
```

其中包含配置、排班、日志、成绩单、识别素材覆盖和备份。源码开发版默认使用 `%LOCALAPPDATA%\Maamaru-Dev`，与安装版分开；两者都使用本机 `8080` 端口，不要同时运行。

### 迁移数据

在启动器中点击“迁移数据”，选择新目录。まあ丸会先完整复制并逐文件校验，再让下次启动切换到新目录。原目录会继续保留；确认新目录能够正常启动后，才可以另行清理旧副本。

复制或校验失败时仍继续使用原目录。不要在迁移过程中手动移动、合并或删除两边文件。

### 卸载

卸载时可以选择保留用户数据，适合换盘、重装或以后继续使用；只有明确选择不再使用并二次确认后，才会删除 `%LOCALAPPDATA%\Maamaru`。

## 仍然不确定怎么配

可以把仓库交给支持项目协作的 Agent，让它先阅读 [`agent-user-guide.md`](agent-user-guide.md)，然后直接描述目标，例如：

> 帮我检查まあ丸，让部队三去 8-1 打十圈；中伤就修好并继续，结束后保持游戏开启。

Agent 应当替你检查现有配置和日志，只询问会实际改变任务结果的必要信息。
