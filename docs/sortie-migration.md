# 出阵拆分与迁移

目标是复用国服已验证的玩法和安全规则，逐步替换服务器画面与连接适配。流程工坊的玩家创作能力不属于本次工作。

## 2026-10-31：共用循环与国服画面适配分开

- `touken/flows/sortie.py` 的 `SortieLoopMixin` 负责每圈选图、准备行军、调用完整安全链、监控、回本丸、伤势恢复后同圈重试，以及真实完成记录。循环不直接访问设备、用户配置、模板文件、OCR 或像素坐标。
- `touken/flows/sortie_cn.py` 的 `CnSortieViewMixin` 提供国服画面观察和操作，包括国服配置绑定、章节页识别、截图、点击、行军停止识别、小地图判读、掉落观察与现有异去界面处理。
- 现有 `SortieMixin` 入口组合这两层。国服与异去的参数、用户自定义坐标、调用方式和日志保留，仍走 `BattleMixin._safe_depart_stream`；异去确认继续复用 `_confirm_departure`。国服普通合战场原本没有二次确认窗，保持原行为。
- 战斗结果、里程碑确认和行军按钮的默认模板通过国服素材包解析。已有用户配置仍优先，不改写配置文件、不新增用户配置字段。

适配接口除了绑定配置，还包括 `_sortie_capture_frame`、`_sortie_tap`、`_sortie_click`、`_sortie_find_deploy`、`_sortie_decide_button`、`_sortie_home_visible`、`_sortie_march_stopped`、`_sortie_wait_decide` 和王点判读能力；现有队伍页、掉落、战斗计数、回本丸等钩子也由适配与宿主提供。

## 验证边界

相关回归覆盖记忆选图跳级、吞点击重试、重伤拦截、自动行军与手动行军、手入同圈续跑、刀装恢复后重设委托、异去提灯消费与账房、掉落三态和战斗计数。

新增测试用没有 `device`、`config` 或国服像素坐标的独立画面宿主跑同一个循环，验证连跑两圈、失败不报完成、伤势恢复后再次走完整安全链。该测试只证明拆分边界，不替代国服或日服实机验收。
