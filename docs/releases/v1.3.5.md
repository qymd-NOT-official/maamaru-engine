# まあ丸 v1.3.5 更新公告

活动建议的时间口径修正，各玩法的判断统一以游戏数据为准；玩家手动操作过游戏后，麻麻露会看现状接着干活，不再抱着旧记录卡死。

## 活动建议

- 活动时间表的「今天建议打几圈 / 挖几层」改按完整游戏日分摊：凌晨收摊的活动不再把最后一圈摊到收摊前一小时，最后一天会把剩余目标收齐。
- 时间表会提示离目标的实际缺口，打完今天建议量但总量还不够时，会继续建议补齐。
- 大阪城「沉眠于地下的千两箱」活动档期更新到 10月15日–10月29日。

## 判断统一以游戏数据为准

- 远征派遣前的重伤检查、刷花换人、编队点名、手入加速符等判断优先以游戏数据为准，画面识别只负责定位和旁证，不再两边打架。
- 手入：擦伤（血量九成以上）的刀慢慢修，不烧加速符；伤势判断与画面不一致时以游戏数据为准并留有记录。
- 任务奖励领取前会先确认有可领取的奖励，空分页不再逐个点开。
- 远征结算有游戏记录时已如实记账，不再凭画面重复入账。

## 手动操作后不再卡死

- 手动收过远征后，麻麻露会与游戏现状对账，销掉旧记录继续安排，不再按旧倒计时白等。
- 补花借队的「待恢复」标记：手动重建队伍或把队伍派出后自动翻篇；标记超过一天自动过期；记录损坏也会留档放行，不再卡死全部出阵。
- 日课刀解：当天已手动刀解过的，日课不再重复解一把。

## 安装与验证范围

请先让任务收工并关闭旧面板，再运行完整安装包。已有配置和本丸记录保存在原用户数据目录。

兼容的近期版本也可通过启动器检查更新；不兼容时请使用完整安装包。

以上改动经过自动回归；这不代表所有模拟器现场均已逐一验证。安装包还会经过更新失败恢复、安装启动和卸载检查。
