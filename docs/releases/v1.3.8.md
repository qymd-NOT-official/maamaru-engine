# まあ丸 v1.3.8 更新公告

这次主要修日服浏览器打不开的问题。

## 日服连接

- 修复「打开日服浏览器」没有反应：部分电脑上的 Chrome 装在当前用户目录下，之前找不到；现在用户级安装、系统级安装都能找到。
- 没有装 Chrome 的电脑，现在可以用 Windows 自带的 Edge 连接日服。
- 点「打开日服浏览器」后，界面会等浏览器真的拉起来再提示结果；没打开时会直接说明原因（比如没找到浏览器），不再假装成功。

## 内部整理

- 出阵与战后返回的共用流程做了一轮整理，行为不变，为后续日服出阵细化打底。

## 安装与验证范围

请先让任务收工并关闭旧面板，再更新。已有配置和本丸记录仍保存在原用户数据目录。

兼容的近期版本可通过启动器检查更新；不兼容时请使用完整安装包。

以上改动经过自动回归，不代表所有现场均已逐一验证。发布安装包还会经过更新失败恢复、安装启动和卸载检查。
