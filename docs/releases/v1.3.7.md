# まあ丸 v1.3.7 更新公告

这次主要是大阪城挖地和出阵前验伤：重伤拦得更准，挖完一层会自动整备接着挖，手入没修好也不再假报完成。

## 大阪城

- 挖完一层后自动检查全队疲劳和刀装：开了自动换队长时，把最精神的队员换到队长位、碎掉的刀装按记录补齐，然后接着挖剩余层数，不从头再来。
- 每次点行军前都重新验伤，不再拿出发时或上一战的老记录做决定。
- 弹出「重伤继续进军？」确认框时，改为认出弹窗文字才点「否」；认不清或点完没关掉就停手叫你看，绝不会误点到背景的「是」。
- 日课新增「凌晨 3 点前推荐圈数」：按近 14 天同一层的实测速度估算换日前还能跑几圈，一键填入；时间不够会直说暂不推荐，给 4 点换日的任务奖励留时间。

## 出阵与验伤

- 修正重伤判定线：血量低于三成才算重伤，游戏里明明挂中伤章的刀不会再被误判成重伤拦下出阵。
- 验伤直接认战斗结算里游戏自己给的伤势结果，手入列表、部队名册、出阵前的说法三处统一。
- 自动换队长拖人后按队员编号核对换没换成；数据不全或没换成时宁可停下本次出阵叫你看一眼，也不带着没验收的队伍出发。
- 手入后伤没修好时，任务成绩明确报「剩余 X 圈/层未完成，已安全停止」，不再假报完成；你自己已经修好的话，旧伤势记录自动翻篇继续跑。

## 异去与普通出阵

- 异去补归城提灯后不再盲点「即刻出阵」，会重新走一遍完整出阵检查（验伤、刀装、委托设置）再出发；普通出阵和异去共用同一套出发流程，口径一致。

## 安装与验证范围

请先让任务收工并关闭旧面板，再更新。已有配置和本丸记录仍保存在原用户数据目录。

兼容的近期版本可通过启动器检查更新；不兼容时请使用完整安装包。

以上改动经过自动回归与部分现场验证，不代表所有模拟器现场均已逐一验证。发布安装包还会经过更新失败恢复、安装启动和卸载检查。
