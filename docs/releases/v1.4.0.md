# まあ丸 v1.4.0 更新公告

这版把麻麻露的「眼睛和手」全部换成自研，顺带修了一批问题。

## 引擎自研（内部大换血）

- 文字识别、图像匹配、触摸翻页全部内置自研，不再捆绑外部自动化框架；安装包更干净，识别速度大幅提升。
- 设置-模拟器新增性能档位：「火力全开 / 省着点跑」，默认省着点跑，挂机更凉快。

## 出阵与日常

- 修复挖地等玩法「刀装补不上就停工」的死循环：记录里存了缺刀装的快照时会越补越空；现在先试用记录恢复，补不上就改为逐成员用游戏自带「自动装备刀装」真补，补完重新保存记录。实在补不上会说明可能是刀装库存不足。
- 出错处理统一为智能处置：某一步出错时会跳过这一步、同时尝试返回本丸，回去了就继续下一步，回不去才停下。任务流和日课里原来的「停下等我/继续下一步」开关随之移除，少一个要记的设置。
- 流程搭建页：流程运行中「运行这条」按钮直接变成「停止工作流」，不用再回执务台停止。
- 锻刀手记：点火记录补上配方；收炉认人改走游戏内记录，不再认书法字（认不出不再是黑洞）。
- 伤势识别改为读章面文字优先、图像兜底，中伤不再被误判成重伤。
- 炼糖：乱舞等级读不清时不再瞎喂。
- 修复异去出阵确认框空等、联队战三倍枡勾选检查、远征收工日志显示 None 等问题。

## 日服

- 文字与画面识别准备就绪，使用内置模型。
- 出阵前会确认队伍状态并拦截重伤；认出公告栏会顺手关掉；内番续班等确认窗默认选「否」。

## 安装与验证范围

请先让任务收工并关闭旧面板，再更新。已有配置和本丸记录仍保存在原用户数据目录。

兼容的近期版本可通过启动器检查更新；不兼容时请使用完整安装包。

以上改动经过自动回归，不代表所有现场均已逐一验证。发布安装包还会经过更新失败恢复、安装启动和卸载检查。
