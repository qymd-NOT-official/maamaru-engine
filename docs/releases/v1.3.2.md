# まあ丸 v1.3.2 更新公告

加入轻量更新支持。普通更新可以复用已有运行环境，只下载程序、界面与项目资源；完整安装包继续用于首次安装、旧版过渡与运行环境变化。

## 更新更轻一些

- 启动器检查更新时显示更新方式与下载大小。运行环境一致且文件完整时优先选择轻量更新包，不匹配时使用完整安装包。
- 下载仍只接受まあ丸官方正式 Release，核对文件名、大小与 SHA-256；下载完成后由你确认更新，任务执行期间暂不开始。
- 轻量更新先在独立目录准备新版，校验文件并检查能否启动，通过后再切换。切换后再次检查，失败时保留或恢复旧程序；轻量更新应用失败后，再次检查会优先选择完整安装包。
- 用户配置、账本、日志、小记与排班继续留在既有用户数据目录。暂存和旧程序副本暂不自动清理。
- 发布流程增加真实程序的轻量升级、损坏新版拦截与切换后回退检查，继续验证安装、首次启动和卸载保留数据。

## 这次怎么升级

**v1.3.1 及以前的单文件版本需要先完整升级一次。** 本次下载安装器 `maamaru-setup-v1.3.2.exe`，或通过旧启动器检查更新并安装。支持轻量更新的版本安装好后，后续相同运行环境的版本才会优先走轻量更新。

免安装版下载 `maamaru-launcher-v1.3.2.zip` 并完整解压，运行 `まあ丸启动器.exe`。新版 EXE 需要旁边的 `_internal` 文件夹，不能只拷贝一个 EXE。

`maamaru-update-v1.3.2-运行环境指纹.zip` 是给已具备兼容运行环境的更新器使用的文件；首次安装或从旧单文件版升级请选择安装器或完整免安装 ZIP，不要手动覆盖轻量包。

升级前让当前任务收工，关闭旧面板和启动器。源码版与安装版默认使用不同的数据目录，但都使用本机 8080 端口，测试安装版时先关闭源码版面板。日服账房、今日安排与自定义任务流继续保留。
