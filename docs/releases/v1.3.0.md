# まあ丸 v1.3.0 更新公告

日服本丸账房加入启动器；国服今日安排集中到规划页，远征、日课和收工行为有了统一入口。

## 日服本丸账房

- 启动器新增「日服本丸」入口，提供本丸首页、仓库和刀帐。
- 连接专用游戏浏览器后，游玩期间更新家底、道具和刀帐记录；两服配置、档案、小记和记录分别保存。
- 修复刀帐与部队状态更新覆盖、历史余额恢复和连接时机问题，补充连接检查与主动诊断入口。
- 日服入口用于账房与记录，不提供国服自动任务。

## 今日安排与一键日课

- 规划页集中设置「规划远征 → 一键日课 → 结束后行为」。首页与规划页执行同一份安排，到点远征确认派出后再跑日课；重复点击不会另起一份任务。
- 系统日课不再重复出现在流程搭建中，自定义流程继续保留。日课、单次玩法和任务流参数独立，旧设置迁入时保留备份。
- 日课采用勾选清单与右侧参数纸笺，时间表默认收起；区分规划远征和单次「指定远征」。
- 签到同时领取万屋暖心礼包；合成单独列在锻刀刀解后面。刀解提供名单跳转。
- 联队战新增「使用建议圈数」，开启后手形不足时自动使用小判补充，关闭后恢复手动设置。没有可靠建议时提示，不退回默认圈数。
- 先行远征失败时停止后续日课与结束动作，保留停止今日安排和中断恢复入口。

## 升级与使用

安装器升级保留用户配置、记录和备份。升级前让当前任务收工，关闭旧面板，再安装新版。

升级后先核对「规划 → 今日安排」：推荐圈数会启用小判补充手形；合成沿用刀解白名单作为素材范围。结束后选择电脑休眠时，休眠期间的后续班次无法开工。

v1.0.1 及以后可在启动器检查更新；更早版本请手动下载安装器。本次仍提供完整启动器和安装器，不提供 Android APK。
