# まあ丸 v1.2.0 更新公告

今天的远征、联队战和日课，可以从主页一键接班。仓库与刀账也补上了玩家常记的掉落、锻刀和成长记录。

## 一键执行今日安排

- 在「我的本丸」待命时，点击「一键执行今日安排」，接下当前建议的远征与联队战；联队战收工后接着跑一键日课。当天已完成的日课会跳过，重复点击不会重复安排。
- 保留已有安排，远征仍按各班时间派遣。执行沿用保存的玩法设置，请先核对部队、伤势处理与资源消耗选项；电脑不能休眠，面板需要保持运行。
- 任务运行时隐藏一键执行按钮，保留「去执务台」查看进度。
- 定时远征会先准备模拟器和登录游戏；联队战遇到远征接班，可在安全节点让路，之后接着打剩余圈数。
- 面板重启导致内置定时联队战意外中断时，主页会提示「去继续」。先在游戏里回到本丸，再确认最后一圈是否已完成，继续剩余圈数。手动停止、安全条件拦截与自定义任务流不自动续跑。

## 不用另开表格的本丸记录

- 「仓库 → 家底」保留小判、四资源、符和甲州金的数量；余额折线只显示小判与四资源，避免几百张符挤在几十万资源的刻度上。整理资源变化提示和折线显示。
- 「全部记录」按日期翻看任务与收支；「掉落统计与锻刀手记」按地图整理掉落，逐炉展示配方、近侍、结果与花费。
- 修复一炉开炉记录错误关联后续多批领取的问题。无法配对的领取单独保留，不猜它属于哪炉。
- 「刀账」展示每一振的等级、累计经验、乱舞与入手日期，展开查看成长和入手履历。同名刀分别记，历史标注保留。
- 补上乱舞进度、内番记录与活动点数历史。乱舞所需振数和疑似喂满带估计标记；缺少的数据不补造，新增采集的历史会随使用积累。

## 本丸庭院与界面

- 可选择季节景趣，也可随机切换；统一庭院、出阵与锻刀场景的像素风格。
- 增加压切长谷部作为庭院伙伴，与小狐狸、狐之助打招呼。
- 整理刀账层次，去掉列表内部滚动；统一金色滚动条，改善窄屏排版。
- 修复景趣资源增多后启动器无法打开的问题，整理启动器布局。
- README 与使用指南同步更新，采用玩家提供的最新截图。

## 升级

安装器升级保留配置、记录与备份。本次不提供独立账房或 Android APK；请从完整面板的「仓库」使用账房。

v1.0.1 及以后可在启动器检查更新；v1.0.0 及更早版本请手动下载安装器。升级前让当前任务收工，再关闭旧面板。

一键执行今日安排已由玩家实机验收。首次使用自己的部队和安排时，仍建议短跑确认。
