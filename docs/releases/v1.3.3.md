# まあ丸 v1.3.3 更新公告

修复远征排班反复打断任务，以及旧派遣记录阻止玩家操作的问题。

## 远征与手动游玩

- 派遣被暂时拒绝后，五分钟冷却期间不再要求日课或活动提前收工。
- 取消、暂停或关闭排班后，清理旧接管请求；已取消的班次不再占住任务位置。
- 续派远征、常用远征和套用部队预设不再按旧倒计时等待或阻止操作。玩家自己收菜或换队后，执行时以游戏里的实际情况为准。
- 去掉“尚未确认收菜”的历史记录拦截。游戏确认出发后，这次派遣即完成；倒计时记录缺失不会导致已完成的班次再次派遣。
- 保留游戏内的操作确认和重伤检查。无法派遣或换队时如实说明，不把未完成的操作记为成功。

自动排班开关管理长期排班；今日单独安排的远征仍按安排执行。要暂时停止全部远征接管，可在自动排班页选择“今天不接管”。

## 更新

v1.3.2 用户可在启动器检查更新，运行环境兼容时使用轻量更新包，不兼容时使用完整安装包。更新前请先让任务收工并关闭旧面板。

本次经过自动回归测试及发布包验证，尚未完成真实游戏中的手动收菜、换队和接续日课验证。遇到异常时请暂停排班并保留反馈包。
