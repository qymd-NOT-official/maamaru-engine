# まあ丸 v1.1.1 更新公告

这次把远征排班、出发前补花和部队预设接成了完整流程，并整理了本丸主页与今天的时间表。

## 远征与刷花

- 远征可以先套用预设、给需要补花的队员刷花，恢复原队伍与装备后再出发。时间表里的每班远征可以单独配置补花和伤势停止条件。
- 普通刷花支持连续轮换本丸刀剑，选带锁、等级不为 1 的刀，可设置本次刷几振；刷到疲劳度 100 再换人，默认自动阵形，兜底鱼鳞阵。
- 选人优先用游戏刀账的唯一编号：按刀种和普通／极形态筛选，找到就选；“带锁、等级最高”先从刀账确定目标，不再为了选一振把名单扫到底再返回。
- 修复胁差筛选、底行数值读取、姓名漏读、滑动漏过中间行，以及目标已在队里时重复换人的问题。
- 修复第一部队解散保留队长和部队记录回传缺少御守字段导致补花误报失败的问题。恢复队伍后仍核对实际成员与装备。
- 旧预设能唯一确认身份时，会先备份再接到游戏编号，避免升级、装备变化造成数值误报；分不清同名刀时仍会停止。

## 今天的时间表

- 规划会给玩家安排的任务流让路，参考最近完成记录估算时长；没有记录时默认留出半小时。
- 支持拖动安排调整时间，以 15 分钟为一格；重叠任务可在同一个浮窗中分别操作。
- 增加明显的刷新按钮，改善任务运行时启用远征建议的操作，移除重复提示。

## 我的本丸与记录

- 保留动态与小记的生活感，使用刀匠、远征队长等角色文案；远征目的地采用游戏叫法。
- 首页增加时间表钟表，便利贴显示远征与锻刀倒计时，整理账房与活动卡片。
- 活动奖励、掉落和补手形收支归入相关执行记录，修复来源翻译与重复展示。
- 单项任务卡片调整为左侧“调整配置”、右侧“开始任务”。

## 独立账房与升级

独立账房入口暂时关闭，本次不再提供 Android 离线账房 APK。请从 Windows 完整面板的“仓库”读取游戏家底、记账与规划；已有账本和手机数据不做删除。

安装器升级保留用户数据目录中的配置、记录与备份。旧版 v1.0.0 及更早版本用户请手动下载安装器升级；v1.0.1 可从启动器检查更新。

本次远征换预设、补花、恢复队伍和派遣已由玩家完成多种情况的实机验收。首次使用自己的预设时，仍建议短跑确认。
