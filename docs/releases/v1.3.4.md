# まあ丸 v1.3.4 更新公告

整理今日安排与远征的停止逻辑，修复演练把空位当成未知成员、漏掉少人对手的问题。

## 今日安排与远征

- “停止今日安排”会停止当前这份安排及它带出的远征、等待和后续任务，保留取消记录；独立安排的任务不受影响。
- “关闭远征安排”会关闭长期排班并取消待执行的远征安排，日课等其他任务可以继续。游戏里已经出发的部队不会被召回。
- 取消后的任务不会因轮询、等待恢复或迟到的启动请求自行续跑；重新安排需由玩家明确操作。
- 已取消、移时或不再需要执行的班次不再凭旧状态占住任务位置。临近出发时仍可取消，修改时间和目的地则保留限制。
- 旧数据中无法确定归属的独立远征，可使用“关闭远征安排”统一停止。

## 演练与日课确认

- 演练优先读取本次对手的完整阵容，修复电脑、模拟器和游戏数据时间不同步时，新记录被误判为旧记录的问题；已确认的空位不会算成未知成员。
- 只能读取画面时明确说明信息不完整，合并重复的身份未确认提示；真正身份不明的成员仍会保守跳过。
- 日课收取、手入、锻刀、刀装和结束后的库存读取优先采用游戏数据；关键操作保留画面确认与安全检查，未确认完成的操作不记为成功。
- 调整部队预设的刀装详情核对，以及疲劳状态读取；活动虚拟记账与实际游玩分开，补充次数需确认结果。

## 日服连接

- 增加日服连续出阵入口、导航与中断恢复，调整菜单识别，减少不同景趣和加载画面的影响。该功能仍需更多实际游玩验证。

## 安装与验证范围

请先让任务收工并关闭旧面板，再运行完整安装包。已有配置和本丸记录保存在原用户数据目录。

兼容的 v1.3.2 / v1.3.3 安装也可通过启动器检查更新；不兼容时使用完整安装包。

安排取消已做隔离界面验证，演练已用本次实际记录回放；这些验证不代表所有模拟器现场均已验证。安装包还会经过自动回归、更新失败恢复、安装启动和卸载检查。
