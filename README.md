## 把重复的事交出去

玩刀剑乱舞九年了，现在还是想玩，只是不想再亲自点完每一轮重复操作，也不想继续手拉 Excel 计算资源。所以我做了まあ丸：需要时替我照看本丸，回来时能翻翻这一天留下的记录。

### 规划：有了记录，再安排今天

家底读入后可以做预算；圈速和收益需要后续运行或手动活动记录，第一次使用不必先做完整规划。活动还差多少、每天大约要打几圈、小判够不够，再按已有记录估一估。联队战建议圈数可以直接排进时间表，也可以自己改时间和圈数；保存的任务流可以单独定时启动。

想补资源，就改规划页的关注项，远征推荐会跟着变。队伍去不了目标地图时，会说明缺什么刀种、总等级差多少或哪张图已经占用；已有部队预设也能用于远征。


### 任务流：把日常顺序存下来

日课、远征、出阵和活动可以按自己的顺序组合，保存后重复使用。每一步保留自己的部队、圈数和消耗设置，不用每天重新点一遍。只想打一项玩法，也可以直接开单个任务。

出发前核对队伍、伤势和刀装；运行中按设置处理手入、补刀装和常见中断。能恢复的继续，无法确认的停下说明原因。任务流结束后，还可以按你选的动作退出游戏、关模拟器或让电脑休眠。


### 仓库与刀账：知道家底，也知道来处

账房把游戏里的资源、物品和活动记录翻译成能看懂的收支，和まあ丸的执行记录一起展示。规划中安排的联队战小判预算也会留在这里，方便看手头还能动用多少。

刀账优先使用游戏所持名单里的唯一编号，同名多振分别记。锻刀、战斗掉落、收件箱领取会留下入手记录；确认过的链结、习合和刀解会更新对应的那一振。自己标记的常用刀、要练的刀也留在刀账里。

游戏记录在手动点击同步或相关任务收工时读取，并非实时监听；不能确认的来源不会编成事实。


### 我的本丸：回来翻翻今天

收刀、远征归来、锻刀和整理刀剑，可以成为带着名字与收获的动态。你也能写自己的小记，换头像、整理审神者档案，让本丸慢慢留住自己的日常。

和纸与像素两套主题随时切换。庭院里的小狐丸和狐之助，也在这里陪着你。


## 第一次使用

在启动器选择 **启动まあ丸**，打开模拟器并进入游戏本丸，然后按自己的需要开始：

**只想跑任务**

去**功能**的执务台/玩法设置选择一个单独任务，核对部队、消耗和停止条件，先短跑一次。可以直接开工，不必先使用账房、读取家底或做规划；想把几件事连起来，再保存成任务流。

**想看家底、记账或做规划**

打开 **仓库**，点 **读取游戏家底**。まあ丸会读取游戏记录，再翻到锻刀与所持道具画面盘点资源、小判和符；不会执行日课、锻刀或出阵。两路结果会分别显示，没读全可以重试。

旧账导入和目标设置都可以跳过。当前家底可用于预算；圈速和收益需要后续运行或手动活动记录，积累后再使用相应的规划建议和时间表。

独立账房入口与 Android APK 暂停提供。请启动まあ丸后，在仓库读取游戏家底、记账和做预算。

## 从哪里开始

| 今天想做什么 | 打开哪个入口 |
|---|---|
| 跑日课、出阵、活动，或按时间表开工 | 启动器里的 **启动まあ丸** |
| 只看记录、记收支、做预算和导入旧账 | **启动まあ丸 → 仓库** |

账房支持 Excel／CSV 导入导出，导入先预览、写入前备份。已有本地账本不会因关闭独立入口而删除。

目前可运行日课与远征、普通合战场、异去第一章、大阪城、江户城 E4、秘宝之里、联队战（含海边之阵）和南瓜大作战。具体玩法设置、开工准备与停止条件请看 [使用说明](docs/user-manual.md)。

## 决定权留给审神者

| 你决定 | まあ丸负责 |
|---|---|
| 今天的目标、任务顺序、部队与阵形规则 | 按保存的安排执行重复步骤 |
| 伤势到什么程度停止，是否手入续跑 | 出发前检查，按条件停下或处理 |
| 是否补手形、花小判、使用道具 | 在许可范围内消耗，不明确时停下 |
| 哪些刀可以参与刀解、链结和习合 | 按名单与保护规则执行 |

读取游戏名单和记录不会直接改动游戏；套用部队预设、出阵和消耗资源属于实际操作，需要你主动启动相应任务。资源建议不会自行替你改编队，联队战建议也要保存为安排才会定时开工。

## 下载与开始

从 [GitHub Releases](https://github.com/qymd-NOT-official/maamaru-engine/releases) 下载：

> [!CAUTION]
> 本项目与游戏运营方无关。正常管家模式包含游戏自动操作，可能违反游戏服务条款，并带来账号处罚、误操作或数据损失等风险；纯净账房不会连接游戏。请自行判断是否使用，并在第一次运行新任务或游戏改版后先短跑确认。

> [!NOTE]
> **项目持续维护中。**主要实测环境是 MuMu 12 与 1280×720 游戏画面；已有长期实机运行和非技术用户安装记录，但新地图、不同模拟器、分辨率或游戏界面更新仍可能影响识别。

## 数据放在哪里

- 安装版的配置、日志、成绩单、手账、规划和备份位于 `%LOCALAPPDATA%\Maamaru`；更新程序不会删除这些数据。
- 源码版默认使用 `%LOCALAPPDATA%\Maamaru-Dev`，避免把开发记录写进安装版账本。
- 成绩单不保存游戏截图；反馈包只包含版本、系统摘要和文本日志，不收集配置、密钥、库存或状态数据库。
- Android 版的数据只在手机应用目录中；目前没有同步或导出，卸载会清除试玩数据，不适合存放无法重新补录的唯一记录。

## 当前边界

- 江户城只智能跑 E4，其他难度不计划适配；
- 部队预设与换装仍在试用，请先用容易复原的队伍短跑查看结果，暂时不要交给无人看守的重要队伍。
- 使用游戏自动行军时，路线和阵形由游戏处理；脚本手动行军时才由まあ丸选择阵形和岔路。
- 南瓜大作战不会自动购买补充令牌；令牌不足时安全结束。
- 王点前撤退、疲劳读取、拖动换队长和掉线恢复都依赖真实画面，无法确认时不会强行猜。
- QQ／Telegram 远程播报尚未完成维护者实机验证，不作为主要功能。
- 紧急停止会直接结束任务进程，无法保证收工盘点或回到本丸；停止后请先查看模拟器当前页面。

<summary><strong>开发者运行与项目结构</strong></summary>

环境要求：Windows、Python 3.12+；正常管家模式还需要 MuMu 模拟器和 ADB。

```powershell
git clone https://github.com/qymd-NOT-official/maamaru-engine.git
cd maamaru-engine
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe maamaru_app.py
```

也可以直接双击 `启动源码版.cmd`。默认面板地址为 `http://127.0.0.1:8080`；安装版和源码版不建议同时运行。

まあ丸由 Python 长任务编排、ADB、MaaFramework、FastAPI 与 Vue 3 / TypeScript 组成。程序文件和用户数据严格分开，旧目录迁移会先复制、备份并校验，不自动删除来源。详细契约见 [用户数据与迁移](docs/data-layout.md) 和 [结构化运行数据](docs/telemetry-data.md)。

```text
maamaru-engine/
├─ launcher/            启动器、更新与数据迁移
├─ panel/               FastAPI 后端和 Vue 本丸面板
├─ ledger_app/          独立账房与 Android 离线版
├─ touken/flows/        日课、出阵、活动、远征与恢复流程
├─ resource/base/       OCR、模型和识别模板
├─ profiles/            活动运行配置
└─ docs/                使用说明、版本记录与开发文档
```

支持仓库协作的 Agent 可以先阅读 [まあ丸 Agent 使用协助规范](docs/agent-user-guide.md)，再帮助玩家检查环境、修改配置或定位停止原因。

</details>
